## 核心概念

| 对象 | 含义 |
| --- | --- |
| Agent | 可复用的角色、引擎和工具配置 |
| Principal / Binding | IM 参与者身份，以及身份到 Agent 配置的绑定 |
| Conversation | 私聊或群聊，保存消息和成员可见性 |
| Discussion | 自动执行的授权范围，承载期限、额度和控制状态 |
| ScheduledTask | 带领取版本与租约的调度单元 |
| Run | 一次具体执行，包含结果、调用诊断及可能的检查点 |
| WorkItem | 可跨多次 Run 的明确工作任务，包含依赖与汇报责任 |

## 更新约定

1. 修改模块边界、进程通信、执行路径或持久化职责时，在同一变更中更新对应图表。
2. 每张图保留最近核对日期、关键约束和代码入口；代码链接使用相对路径，注明关键符号。
3. 图中只描述已实现行为。拟议功能不写入这里，落地后再更新。
4. 代码与历史设计冲突时，以当前代码为准；核对后更新日期，不仅修改日期。
5. 提交前检查 Mermaid 渲染、相对链接和流程分支，尤其是授权、挂起、失败与恢复边界。

Markdown 中的 Mermaid 是图表唯一维护源；如需导出 SVG/PNG，从该源生成，避免另维护一套图。
这些图帮助定位实现，不替代详细协议、权限契约或测试。
