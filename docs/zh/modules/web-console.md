# Web 控制台

| 概览 | |
| --- | --- |
| **是什么** | AGT Studio，agt 的本地浏览器界面 |
| **启动** | `agt web` |
| **依赖** | 只需要 `agt`：控制台内置在其中 |
| **代码** | `web/public/`（原生 HTML/CSS/JavaScript，无需构建）和 `crates/agt-cli/src/web/`（本地服务），都内置在 `agt` 中 |

## 作用

Web 控制台是 `agt` CLI 之上的轻量本地界面：每个操作都调用 CLI，因此这里能做的事在终端中也都能做。服务同时运行调度器，所以发送消息后 Agent 会立即回复。

控制台有中文和英文两种语言，默认跟随浏览器语言；可以用右上角的语言菜单切换，选择会记在当前浏览器里。

## 怎么用

```bash
agt web
```

打开终端打印的完整链接，包括 `#` 后面的令牌。在远程服务器上使用 SSH 隧道（`ssh -N -L 4317:127.0.0.1:4317 user@server`）；见[安装](../guide/installation.md#在远程服务器上运行)。

## 常用参数

| 参数 | 含义 |
| --- | --- |
| `agt --home <目录> web` | 要打开的工作空间（默认 `$AGT_HOME`，否则 `~/.agt`） |
| `--port <n>` | `127.0.0.1` 上的端口（默认 4317） |

## 全部参数

### `agt web`

| 选项 | 默认值 | 含义 |
| --- | --- | --- |
| `--port <n>` | `4317` | 端口。控制台只监听 `127.0.0.1`。 |
| `--principal <id>` | `web-operator` | 你的身份。第一个在某个 home 上启动控制台的身份会成为工作空间负责人；之后启动必须使用同一身份。 |
| `--home <目录>`（全局） | `$AGT_HOME`，否则 `~/.agt` | home 目录；写在 `web` 前面 |

`agt web` 直接从 `agt` 程序本身提供页面，每个操作都以同一个 home 执行一条 `agt` 命令，因此控制台和调度器始终使用同一个版本。按 Ctrl+C 会同时停止控制台和调度器。

首次启动时，控制台会创建你的用户身份。启动时不会为旧消息调用模型。

### 从源码运行

在克隆的仓库中，`cargo run -p agt-cli -- web` 从工作区源码启动控制台。`web/public/` 下的文件在构建时嵌入，修改其中任何文件后 Cargo 都会重新构建 `agt`。

### 页面

左侧栏有六个页面。点击左上角的菜单按钮可以显示页面名称。

| 页面 | 在这里做什么 |
| --- | --- |
| **会话空间** | 在私聊和群聊中与 Agent 对话 |
| **Agent 团队** | 创建、编辑、启用和停用 Agent |
| **Agent 会话** | 只读查看任意 Agent 的会话 |
| **交互观察** | 查看谁和谁对话、委派了哪些任务；打开审批队列 |
| **资源库** | 管理 Provider、Model、Prompt、Skill、MCP 服务和 Harness |
| **运行设置** | 工作空间设置：调度、审批、记忆、本机命令 |

右上角有**外观**（跟随系统、浅色或深色）、语言菜单和**调试模式**（显示执行 ID、调用次数和错误码）。**Ctrl/⌘+K** 打开命令面板，可跳转到会话、Agent 和页面。

### 会话空间

三栏布局：会话列表、消息区和**成员状态**。右上角的两个面板按钮可以收起两侧栏；旁边是**新建会话**。

**会话列表。** 显示最近活动时间和未读数。搜索框可以查找会话和人；点击某个人会打开你和他的私聊。右键会话（或使用 **⋯**）可以打开、查看信息或从列表中移除。

**标题栏。**

| 按钮 | 作用 |
| --- | --- |
| **继续回复** | 让 Agent 回复未开启自动回复时保存的消息，或延长已过期的讨论 |
| **停止本群 Agent** | 结束本轮，停止在这里工作的 Agent |
| **任务** | 本会话的[任务面板](./tasks.md) |
| **会话控制** | `/` 命令 |
| **群信息** / 会话信息 | 成员、退出、解散、重置上下文 |

**输入框。** 输入 `@` 提及成员，输入 `/` 使用命令。**发送后自动回复**决定发送时是否开始一轮讨论。消息支持 Markdown：列表、代码、粗体、引用和链接。

**Agent 工作时。** 输入框上方的执行横条显示每个正在运行的 Agent、当前阶段、回复预览及其工具调用。有审批等待时会自动展开。执行结束后，记录会挂到它产生的消息下方：工具调用、耗时和失败数，并提供完整执行记录的链接。

**成员状态。** 每个成员正在做什么（判断、等待发言、回复、等待）以及原因。点击某一行查看最近一次决定的原因和时间。

### Agent 团队

每个 Agent 一张卡片。**创建 Agent**打开的表单见[创建 Agent](../guide/agents.md#在-web-控制台中)。每张卡片上有：

- **编辑角色**：说明、执行方式和模型、Prompt、Skill、MCP 服务、内置工具。
- **发起私聊**。
- **配置与管理**：启用或停用、响应策略和工作目录、查看它使用的资源、删除。

点击 Agent 的名字或头像打开详情：当前状态、参与的会话、最近执行和能力配置。可以多选卡片批量启用或停用。

### Agent 会话

选择一个人或 Agent，再选择其中一个会话，即可按对方视角阅读。这个视图是只读的：不能以其他身份发送消息。**整理会话**可以一次隐藏或恢复该 Agent 的多个会话入口。

### 交互观察

Agent 之间消息和任务委派的关系图，支持筛选。点击节点或连线查看详情。**权限审批**打开整个工作空间的审批队列；见[权限审批](./permissions.md)。

页面默认使用**全局视角**：显示任一身份能看到的所有会话，包括你不在其中的 Agent 之间的私聊，比如 lead 给 Codex Agent 布置任务。页面每隔几秒自动刷新。想看某个 Agent 自己能看到什么，在**观察范围与筛选**里选择它。

### 资源库

每种资源一个标签页。**新建资源**创建资源；点击资源查看详情。Provider 直接填写 API Key；Model 提供**获取模型列表**；Harness 提供**读取可用模型**和**检查连接**。

删除需要确认；资源仍被其他资源或已启用的 Agent 使用时会被拒绝。在控制台中删除无法撤销。

### 运行设置

分为**调度与容量**、**工具权限审批**、**跨会话记忆**和**本机执行**几部分。每项设置都显示默认值和修改的生效时机。见[工作空间与配置](./workspace.md#config-yaml)。

### 输入框命令

在输入框输入 `/` 可列出当前会话可用的命令。命令不会作为消息发送；要发送以 `/` 开头的文字，输入 `//`。

| 命令 | 含义 |
| --- | --- |
| `/help` | 列出命令 |
| `/new`、`/clear` | 重置 Agent 在这里的工作上下文；保留聊天记录 |
| `/stop` | 结束本轮，停止在这里工作的 Agent |
| `/status` | 每个 Agent 的状态、执行方式和最近执行 |
| `/timers` | 本会话的定时任务，可以取消 |
| `/model` | Codex Agent：选择本会话的模型和推理档位 |
| `/compact` | Codex Agent：压缩上下文 |
| `/rename` | Codex Agent：为会话命名 |
| `/skills`、`/mcp` | Codex Agent：Codex 中配置的 Skill 和 MCP 服务 |
| `/permissions` | Codex Agent：会话的文件权限 |

### 快捷键

| 按键 | 操作 |
| --- | --- |
| Ctrl/⌘+K | 命令面板 |
| Ctrl/⌘+Enter | 发送 |
| `@` | 提及成员 |
| `/` | 命令 |
| Shift+F10 | 打开当前会话的右键菜单 |
