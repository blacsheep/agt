# Web 控制台

Web 控制台（AGT Studio）是 `agt` CLI 之上的本地界面。用 `node web/server.mjs` 启动，并打开它打印的完整链接；
见[安装](../guide/installation.md#启动-web-控制台)。

## 页面

左侧栏有六个页面。点击左上角的菜单按钮可以显示页面名称。

| 页面 | 在这里做什么 |
| --- | --- |
| **会话空间** | 在私聊和群聊中与 Agent 对话 |
| **Agent 团队** | 创建、编辑、启用和停用 Agent |
| **Agent 会话** | 只读查看任意 Agent 的会话 |
| **交互观察** | 查看谁和谁对话、委派了哪些任务；打开审批队列 |
| **资源库** | 管理 Provider、Model、Prompt、Skill、MCP 服务和 Harness |
| **运行设置** | 工作空间设置：调度、审批、记忆、本机命令 |

右上角有**外观**（跟随系统、浅色或深色）和**调试模式**（显示执行 ID、调用次数和错误码）。
**Ctrl/⌘+K** 打开命令面板，可跳转到会话、Agent 和页面。

## 会话空间

三栏布局：会话列表、消息区和**成员状态**。右上角的两个面板按钮可以收起两侧栏；旁边是**新建会话**。

**会话列表。** 显示最近活动时间和未读数。搜索框可以查找会话和人；点击某个人会打开你和他的私聊。
右键会话（或使用 **⋯**）可以打开、查看信息或从列表中移除。

**标题栏。**

| 按钮 | 作用 |
| --- | --- |
| **继续回复** | 让 Agent 回复未开启自动回复时保存的消息，或延长已过期的讨论 |
| **停止本群 Agent** | 结束本轮，停止在这里工作的 Agent |
| **任务** | 本会话的[任务面板](../guide/tasks.md#在-web-控制台中) |
| **会话控制** | `/` 命令 |
| **群信息** / 会话信息 | 成员、退出、解散、重置上下文 |

**输入框。** 输入 `@` 提及成员，输入 `/` 使用命令。**发送后自动回复**决定发送时是否开始一轮讨论。
消息支持 Markdown：列表、代码、粗体、引用和链接。

**Agent 工作时。** 输入框上方的执行横条显示每个正在运行的 Agent、当前阶段、回复预览及其工具调用。
有审批等待时会自动展开。执行结束后，记录会挂到它产生的消息下方：工具调用、耗时和失败数，并提供完整执行记录的链接。

**成员状态。** 每个成员正在做什么（判断、等待发言、回复、等待）以及原因。点击某一行查看最近一次决定的原因和时间。

## Agent 团队

每个 Agent 一张卡片。**创建角色**打开的表单见[创建 Agent](../guide/agents.md#在-web-控制台中)。每张卡片上有：

- **编辑角色**：说明、执行方式和模型、Prompt、Skill、MCP 服务、内置工具。
- **发起私聊**。
- **配置与管理**：启用或停用、响应策略和工作目录、查看它使用的资源、删除。

点击 Agent 的名字或头像打开详情：当前状态、参与的会话、最近执行和能力配置。可以多选卡片批量启用或停用。

## Agent 会话

选择一个人或 Agent，再选择其中一个会话，即可按对方视角阅读。这个视图是只读的：不能以其他身份发送消息。
**整理会话**可以一次隐藏或恢复该 Agent 的多个会话入口。

## 交互观察

Agent 之间消息和任务委派的关系图，支持筛选。点击节点或连线查看详情。**权限审批**打开整个工作空间的审批队列；
见[权限审批](../guide/permissions.md)。

## 资源库

每种资源一个标签页。**新建资源**创建资源；点击资源查看详情。Provider 直接填写 API Key；Model 提供**获取模型列表**；
Harness 提供**读取可用模型**和**检查连接**。

删除需要确认；资源仍被其他资源或已启用的 Agent 使用时会被拒绝。在控制台中删除无法撤销。

## 运行设置

分为**调度与容量**、**工具权限审批**、**跨会话记忆**和**本机执行**几部分。每项设置都显示默认值和修改的生效时机。
见[运行配置](./configuration.md)。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| Ctrl/⌘+K | 命令面板 |
| Ctrl/⌘+Enter | 发送 |
| `@` | 提及成员 |
| `/` | 命令 |
| Shift+F10 | 打开当前会话的右键菜单 |
