# Architecture

::: info Chinese only
The architecture and design docs are written for contributors and are currently in Chinese:
[架构图与执行流程](/zh/architecture/).
:::

They cover the overall architecture, how resources, messages, runs and tasks flow, and design
topics such as the scheduler, the native loop, context management, Codex integration,
approvals and the Web console.

The [Guide](/guide/what-is-agt) and [Modules](/modules/workspace) sections cover how to use agt
in English.
