# AGT Studio 界面规范

## 设计方向

安静的协作工作台：浅灰画布、白色内容面、只在需要分隔时用细线，层次主要靠底色和留白区分。
靛蓝是唯一的品牌色，用于主操作、选中和焦点；每个身份有固定的识别色，贯穿头像、消息署名和成员状态。
聊天是主任务，状态与资源管理是辅助任务；不以卡片数量表达信息丰富度。

签名元素：
- **品牌标识**：靛蓝到紫的渐变方块；空状态用同一渐变的圆环图形。
- **身份色**：8 种色调（`data-tone`），由身份 ID 稳定推导；页面 CSP 禁止内联样式，所以颜色只通过类与属性选择器设置。
- **工作光环**：Agent 思考或回复时，头像和执行卡片外圈显示旋转的渐变光环；尊重“减少动态效果”。
- **对话气泡**：自己发的消息为靛蓝实底白字靠右；其他成员为白色气泡靠左，署名使用其身份色；同一发送者 5 分钟内的连续消息合并。
- **悬浮输入框**：圆角卡片落在画布上，聚焦时出现靛蓝外光。

## 设计令牌

样式表开头的 `:root` 定义语义令牌，深色主题在 `:root[data-theme=dark]` 中覆盖同名令牌：

| 类别 | 令牌 |
| --- | --- |
| 表面 | `--canvas` `--surface` `--surface-2` `--hover` `--selected` |
| 文字 | `--text` `--text-2` `--text-3` |
| 边框 | `--border` `--border-strong` `--control-border`（控件边界，≥3:1） |
| 强调 | `--accent`（文字/图标）`--accent-fill`（实底）`--accent-strong` `--accent-soft` `--accent-soft-2` `--accent-text` |
| 状态 | `--success` `--warning` `--danger` 及各自 `-soft` 底色 |
| 形状 | `--r-sm` `--r-md` `--r-lg`、`--shadow-sm/md/lg` |

新样式只使用语义令牌。较早的专项面板（任务、设置行、交互观察等）仍有 `var(--s-<hex>, #hex)` / `var(--i-<hex>, #hex)`
形式的颜色：它们在深色块里有对应值，蓝色系已统一映射到靛蓝令牌。改动这些面板时，顺手换成语义令牌。

两种主题的文字对比度都需达到 WCAG AA（正文 4.5:1，大字 3:1）。外观可选跟随系统、浅色、深色；
`theme.js` 在首帧前设置 `data-theme`。

## 布局与交互

- 大屏以窗口为边界：左侧导航（可展开名称）、会话列表、聊天、成员状态四列；会话页工具放在顶栏。
- 其他页面统一使用一个页面标题：标题 + 一句说明 + 右侧操作，不使用英文装饰标签。
- 会话列表显示最后一条可见消息预览、时间和未读数；打开会话即标记已读，观察 Agent 时不改变其已读位置。
- 未选中会话时隐藏会话操作；“继续回复”“停止 Agent”只在可用时出现；批量启停按钮只在有选择时出现。
- 成员摘要先显示身份与状态，理由用两行预览，详情按需展开，刷新时保持展开与键盘焦点。
- 逐条消息的次要操作只在悬停或聚焦时出现；搜索可用 Ctrl/⌘+K 聚焦；右键操作必须同时有可见按钮入口。
- 手机先显示会话列表，打开会话后进入阅读视图并可返回；顶栏单行，操作栏横向滚动。
- 动画服从减少动态效果设置；颜色、阴影和动效不能替代明确文字状态。
- 空状态说明当前该做什么：没有会话时引导新建，有会话未选中时引导从列表选择。

验证：桌面与手机横向无溢出，输入区与消息区可达，搜索、菜单、@、整理、上下文重置和只读观察都保持可操作；
两种主题都做对比度自动检查。使用本地测试数据截图，不向真实模型发请求。

会话命令统一在“会话控制”侧面板中操作：桌面与聊天并排，打开时临时替代成员状态；
中屏临时收起联系人列，手机使用整屏面板。关闭后恢复原布局偏好。
聊天顶部“会话控制”按钮可展开或收起，面板内支持 Escape 返回；切换会话或页面关闭面板并废弃旧请求。
模型、档位、命名、压缩、Skills、MCP 和权限共用命令导航，群内切换命令保留目标 Agent。
重置与停止在面板内明确确认；成功与错误就地显示，连接详情默认折叠。


控件对比度：次要按钮保留可辨认边框（与背景 ≥3:1），主操作用靛蓝实底，危险操作使用红色文字与边框。
禁用状态以灰底、灰字和 disabled 语义区分，不整体降低透明度。悬停与键盘焦点不能只靠透明度。

命令按当前聊天成员的执行能力显示。内置 Agent 的 /model 标注“查看模型”，
Codex 专属命令带 Codex 前缀且仅在存在有效 Codex 目标时出现。
混合群聊的专属操作只列 Codex 目标，提供所有 Agent 的模型/状态入口；
/status 覆盖所有运行身份。手动输入不适用命令保留草稿、说明原因，不发执行请求。

执行横条采用渐进展开：默认只显示 Agent、当前工具或并行操作数、总耗时；
展开后显示最近结束的操作和仍在执行的操作，使用可读名称、等宽工具名、状态、耗时和安全摘要。
执行卡片与 Agent 消息同样落在画布上，运行中以渐变光环标识；不新增弹窗或自动抢占焦点。
框架工具信息由审计投影提供；模型内部推理、工具参数和返回正文不进入公开横条。
未确认结束的工具在终态记录中标为“状态待确认”，不能假装成功或仍在运行。

运行设置使用独立页面，按权限、调度、记忆、本机执行分区，选项左侧解释用途与生效时间、右侧放控件。
宽屏左侧有分区目录并随滚动高亮；修改过的行有左侧标记，底部固定的保存栏显示未保存项数。
配置说明来自后端契约，技术键默认折叠；不限使用独立复选框，不用 0 代替。
保存携带读取时的配置以检测并发修改；失败保留草稿，重新读取前明确确认放弃未保存修改。
本机执行默认关闭，文案明确“工作目录不是沙箱”，Agent 能力挂载与全局授权分开展示。

终止信息分为执行状态、触发原因和停止确认，任务详情内用单个灰蓝边框区域呈现。
诊断标识折叠，公开时间线显示原因记录、停止请求、确认与任务终态；不展示 stderr 或私有输出。
讨论到期时仍在运行的任务显示“继续执行中”，待处理通知明确显示“等待授权续期”。

交互观察以可交互拓扑为主：点阵浅色画布、右侧详情、顶部折叠筛选和底部折叠消息记录。
Agent 使用圆形节点，群聊使用菱形节点；私聊连线保留方向，群聊消息连接发送者与群节点，
成员关系为虚线，不将成员关系伪装成消息投递或阅读确认。节点标签保留名称及文字状态。
节点可拖动，背景可平移，滚轮和按钮缩放，支持适应全图和布局复位；点击节点聚焦一跳关系，
点击连线打开最近消息详情。键盘 Enter 选择、方向键移动、Escape 取消聚焦，尊重减少动画偏好。
执行光环由框架当前状态驱动，离线时标为待确认；仅刷新发现的新消息触发 6.5 秒流动高亮，
初次加载或翻阅历史不播放实时动画。工具详情、公开理由与消息时间分开，不能把当前状态当作历史状态。
消息两行预览，详情默认展示 160 字，其余手动展开；中小屏详情移至图下方，控件保持可达。
观察身份沿用会话权限，切换时清空图、消息和动画并废弃过期响应。初次分批读取六个会话各最近 30 条，
明确载入范围；按会话可读取更早消息，筛选仅作用于已载入记录。刷新由现有事件流驱动。
未记录公开理由时如实说明，不将模型内部推理、私有工具参数或输出当成公开解释。
