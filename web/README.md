# AGT Studio

The local Web console for agt. 本目录是 agt 的本机 Web 控制台。

```bash
cargo build -p agt-cli
node web/server.mjs
```

Open the full link printed in the terminal, including the token after `#`.
打开终端打印的完整链接（包括 `#` 后的令牌）。
